# Research Agenda

## Core Theme
**Trustworthy information and secure intelligent systems in the age of AI.**

My applied research program examines how AI systems can be made more reliable, secure, explainable, privacy-aware, and useful in real operational environments.

## Research Pillars

### 1. LLM Evaluation
- Factuality and hallucination
- Groundedness
- Robustness
- Task-specific benchmarking
- Human evaluation
- Calibration and uncertainty
- Evaluation of prompts, agents, and workflows

### 2. Prompt Engineering
- Systematic prompt design
- Prompt optimization
- Prompt sensitivity
- Prompt injection resistance
- Structured prompting for scientific and enterprise workflows

### 3. Trustworthy AI
- Reliability
- Transparency
- Accountability
- Explainability
- Human oversight
- Bias and fairness
- Privacy and security

### 4. AI Governance
- AI risk management
- Model documentation
- Responsible deployment
- Organizational controls
- Policy-to-implementation translation

### 5. Retrieval-Augmented Generation
- Retrieval quality
- Provenance
- Source credibility
- Trust-aware retrieval
- RAG evaluation
- Security of external context

### 6. AI + Cybersecurity
- ML for threat detection
- Adversarial ML
- LLM security
- Prompt injection
- Data poisoning
- Security analytics
- Human factors in cybersecurity
