## Featured Research Projects

### 1. LLM Evaluation
Develop reproducible evaluation pipelines for LLM quality, groundedness, hallucination risk, robustness, safety, and task-specific performance.

**Research questions**
- How should LLM performance be measured beyond simple accuracy?
- How can evaluation incorporate trust, uncertainty, robustness, and human judgment?
- How do prompting and retrieval strategies affect factual reliability?

### 2. RAG Security
Investigate security, privacy, and trust risks in retrieval-augmented generation systems.

**Research questions**
- How vulnerable are RAG systems to prompt injection and malicious retrieved content?
- How can source provenance and trust scores improve retrieval?
- What controls reduce data leakage and untrusted-context influence?

### 3. Trustworthy AI
Explore practical methods for building AI systems that are reliable, transparent, accountable, privacy-aware, and aligned with organizational governance requirements.

### 4. Cybersecurity + Machine Learning
Apply machine learning to threat detection, anomaly detection, security analytics, phishing detection, and risk prioritization while examining adversarial and operational limitations.
