# Project: RAG Security

## Goal
Study security and trust risks in Retrieval-Augmented Generation systems.

## Threat Model
- Prompt injection in retrieved documents
- Poisoned knowledge-base content
- Sensitive information leakage
- Untrusted sources
- Retrieval manipulation
- Context-window attacks

## Research Directions
- Trust-aware document ranking
- Source provenance scoring
- Prompt-injection detection
- Retrieval sanitization
- Access-control-aware RAG
- Security-focused RAG evaluation
