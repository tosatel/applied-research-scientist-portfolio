# Feature dictionary

All values are synthetic, normalized 0–1 proxies, not verified facts.

- `language_consistency`: internal linguistic consistency proxy
- `claim_specificity`: specificity of presented claim proxy
- `source_history`: hypothetical source reliability history proxy
- `provenance_quality`: hypothetical traceability/provenance proxy
- `independent_corroboration`: hypothetical independent support proxy
- `context_alignment`: hypothetical contextual agreement proxy
- `label`: simulated binary outcome (1 = synthetic higher-trust class)
