# Project: Cybersecurity + Machine Learning

## Goal
Apply machine-learning methods to cybersecurity problems while evaluating operational robustness and adversarial limitations.

## Candidate Studies
- Network anomaly detection
- Phishing detection
- Malware classification
- User/entity behavior analytics
- Threat-intelligence NLP
- Alert prioritization
- Adversarial evasion experiments

## Evaluation
Include precision, recall, F1, ROC-AUC where appropriate, false-positive analysis, class imbalance, operational cost, and security implications.
