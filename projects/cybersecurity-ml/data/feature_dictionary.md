# Feature Dictionary

| Feature | Meaning |
|---|---|
| failed_logins | Failed authentication attempts in the observation window |
| connection_count | Number of connections in the observation window |
| unique_destinations | Distinct destinations contacted |
| bytes_mb | Approximate transferred data in MB |
| session_minutes | Session duration in minutes |
| off_hours | 1 if event occurred outside normal working hours |
| privileged_action | 1 if privilege-sensitive activity was observed |
| baseline_deviation | Standardized deviation from historical activity |
| label | 1 = synthetic anomalous event, 0 = synthetic routine event |
