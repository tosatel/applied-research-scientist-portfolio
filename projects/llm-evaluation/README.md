# Project: LLM Evaluation

## Goal
Build a reproducible framework for evaluating LLM systems across quality, factuality, groundedness, robustness, safety, and task utility.

## Candidate Metrics
- Accuracy / F1
- Semantic similarity
- Groundedness
- Citation correctness
- Hallucination rate
- Refusal correctness
- Robustness under prompt variation
- Human preference
- Latency and cost

## Planned Experiments
1. Compare prompting strategies.
2. Compare models on a domain-specific benchmark.
3. Measure hallucination under insufficient context.
4. Evaluate retrieval-grounded versus non-retrieval generation.
5. Conduct structured error analysis.
